# بوت تيليجرام لتحويل الصوت إلى نص محلياً

يستقبل البوت الرسائل الصوتية وملفات الصوت والفيديو، ويفرّغ الكلام على جهاز
المشغّل باستخدام `faster-whisper`. يتضمن رسائل عربية، وحصة استخدام يومية،
وفحوصاً لجودة النص، ولوحة متابعة محلية.

التفريغ محلي، بينما ينقل تيليجرام الملفات والنصوص بين المستخدم والبوت.
يلزم توكن بوت تيليجرام، ولا يلزم مفتاح لخدمة تفريغ مدفوعة.

## التشغيل

ثبّت `Python 3.13` و`FFmpeg`، وتأكد من توفر الأمرين `ffmpeg` و`ffprobe`.
أنشئ بيئة افتراضية وثبّت الاعتماديات:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements-lock.txt
Copy-Item .env.example .env
```

أضف توكن البوت إلى ملف `.env` ثم شغّل:

```powershell
python bot.py
```

ملف الإعدادات التجريبي يختار نموذج `small` على المعالج باستخدام `int8`.
تُنزّل أوزان النموذج عند أول تفريغ. لتشغيل لوحة المتابعة في طرفية أخرى:

```powershell
python dashboard_server.py
```

## ما الذي يضيفه المشروع؟

- تحويل الملفات إلى صوت أحادي بتردد `16 kHz` وفحص المدة قبل التفريغ.
- كشف اللغة تلقائياً، مع معالجة تجريبية للكلام المختلط بين العربية والإنجليزية.
- فحوص للصمت والتكرار وتسرب تعليمات النموذج وضعف الثقة، وإعادة محاولة مشروطة.
- تقسيم متداخل للصوت عند الحاجة، وإرسال ملف نص عادي وآخر بطوابع زمنية.
- إدارة الحصص اليومية والأرصدة والحظر وتسجيل النتائج في قاعدة `SQLite`.

## الحدود

لم تُقَس دقة التعرف على الكلام بمعيار منشور. فحوص الجودة قواعد استدلالية
قد ترفض كلاماً صحيحاً أو تقبل نصاً خاطئاً. قد يكرر التقسيم بعض الكلمات عند
حدود المقاطع. تمييز المتحدثين غير منفذ، والبوت مخصص لعملية تشغيل واحدة.

لوحة المتابعة تعمل على الجهاز المحلي دون تسجيل دخول. الصوت المحفوظ اختيارياً
له تنظيف عند بدء التشغيل، بينما التفريغات وقاعدة البيانات لا تُحذف تلقائياً.
لا تنشر مجلد `data` أو ملف `.env`.
